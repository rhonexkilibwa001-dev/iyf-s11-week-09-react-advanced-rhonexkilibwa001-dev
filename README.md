# Week 09 — React Advanced

This repository contains the scaffold and initial implementation for the Week 9: React Advanced assignment.

Status

- Initial scaffold and core features implemented on branch `feature/week-09-react-advanced`.
- Posts page includes Create Post form that POSTs to JSONPlaceholder and updates the UI locally.
- Exercises page with useEffect and custom-hook demos added.
- Accessibility improvements: aria-labels on forms and nav landmarks.

How to run locally

1. Clone the repo
2. Checkout branch: feature/week-09-react-advanced
3. Install and run:

   npm install
   npm run dev
