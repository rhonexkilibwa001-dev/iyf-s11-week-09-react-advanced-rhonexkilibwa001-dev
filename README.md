# Week 09 — React Advanced

This repository contains the scaffold and initial implementation for the Week 9: React Advanced assignment.

What I added on branch feature/week-09-react-advanced

- Vite + React scaffold (basic package.json and app files)
- React Router with routes: /, /posts, /posts/:id, /about
- Components: Header, PostList, PostCard, PostForm
- Hooks: useFetch, useLocalStorage
- Basic responsive styles using CSS Modules
- Data fetching uses JSONPlaceholder (https://jsonplaceholder.typicode.com) as a fallback API

How to run locally

1. Clone the repo
2. Checkout branch: feature/week-09-react-advanced
3. Install and run:

   npm install
   npm run dev
